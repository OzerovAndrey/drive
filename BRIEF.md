# DRIVE — product brief

## Goal

Demonstrate Product/UX thinking and a shared multi-brand design system through a usable automotive selection journey. Work in this independent repo; do not edit Portfolio, Atlas or the casino demo.

## Accepted visual direction

- TORQ: racing editorial, condensed Barlow Condensed, graphite / white, lime accent, 4px geometry.
- VOLT: technological, geometric DM Sans, navy / cool white, cobalt accent, 16px geometry.
- FORMA: considered luxury, Cormorant Garamond display + Inter UI, espresso / ivory, bronze / champagne, 8px geometry.
- One shared product/data set, navigation and logic. Brand mode changes identity, not inventory.
- Studio automotive photography, expressive type, restrained parallax, reveal and hover motion.
- Light themes have genuinely light surfaces. Dark themes retain legible semantic text.

## Scope

Home, catalogue, model detail, comparison, saved cars, four-step configurator, guided matching, local test-drive confirmation, explanatory page and component specimen page. Desktop and mobile. No real payment, inventory, dealership booking, backend account or external transmission.

## Development stages

1. Working site and token-compatible code in GitHub.
2. Complete Figma library and screens using those tokens, including all six configurations and relevant states.
3. Export documentation to the owner's local disk (requires a reachable local destination; the hosted workspace is not the user's computer).

## Current status

Expanded v2 implementation: detailed specifications and equipment, location photography, gallery, cabin hotspots, electric education, energy/charging calculators and editorial guides. Stage 2 Figma component library created; full page recreation remains separate. See QA notes for exactly what was verified. Never describe Figma as synchronized until performed and verified.
