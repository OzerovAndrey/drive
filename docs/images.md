# Automotive imagery

Three fictional automotive studio photographs were created with the built-in image-generation tool for this project and delivered as optimized WebP. They are not manufacturer product photography. Source PNGs remain local and are ignored by Git; the shipped assets are public/images/volt.webp, torq.webp and forma.webp.

## Prompt set

Common prompt: Use case product-mockup. Production photograph asset for DRIVE automotive website, not a website mockup. Wide 16:9 premium studio automotive campaign photograph. Fictional automobile, no manufacturer emblems, no text, no watermark. Whole car comfortably visible, low front three-quarter camera facing left, centered horizontally with breathing room above. Matte medium neutral gray seamless cyclorama and slightly lighter concrete floor, soft contact shadow. Photoreal materials, tire detail, soft dramatic key light, credible proportions; uniform neutral background suitable for light and dark compositions. One car only, no interface, people or other cars.

- TORQ: sleek silver performance coupe, sculpted hood, slim LED headlights, dark alloy wheels.
- VOLT: pearl white electric fastback sedan, aero wheels, restrained futuristic design, sleek LED headlights.
- FORMA: deep forest-green premium SUV, large elegant wheels, subtle bronze detailing.

The implementation intentionally uses shared collection data and image content across appearance brands. Brand hero selects a different featured model while saved IDs, comparison and configuration remain intact.

## v2 production assets

Built-in image generation created three location photographs from each original vehicle reference and one new collection cabin study. Shipped WebP paths:

- public/images/torq-road.webp — reference silver coupe on an alpine pass at blue hour.
- public/images/volt-road.webp — reference white sedan beside a coastal architectural charging point.
- public/images/forma-road.webp — reference green SUV, rear three-quarter, beside a forest lodge at sunrise.
- public/images/cabin.webp — shared black/tan cabin, panoramic roof, tactile controls, soft amber trim lighting.

Prompt set: preserve the reference car's body/color/wheels in a photoreal wide editorial location scene, no text/logos/people/UI. For the cabin, create an explicitly fictional collection interior seen from rear seats toward the dashboard, premium materials, panoramic forest view and no manufacturer marks. The cabin is not claimed as the exact interior of every model.
